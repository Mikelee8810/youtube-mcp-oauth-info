Privacy Policy — YouTube MCP

Last updated: October 8, 2026.

What data is used

With the account owner's consent, the application uses the Google YouTube Data API to access information about their authorized YouTube account and to perform only the actions the owner requests. Access depends on the Google OAuth scopes the owner approves.

Where data goes

The MCP service runs on the account owner's computer. OAuth credentials are stored locally, and tokens are exchanged with Google's authentication services. When the owner calls YouTube MCP tools inside ChatGPT, relevant requests and returned information are sent between the owner's MCP service and ChatGPT through a dedicated connector tunnel, and may be processed under OpenAI's applicable privacy terms. API calls are made to Google to fulfill the request.

Storage and sharing

The application itself has no advertising, user analytics or data-sales service. The local MCP may keep configuration, OAuth tokens and necessary operational files on the owner's computer. This public information website is hosted by GitHub Pages, which may collect standard hosting information under GitHub's privacy policy.

Control and deletion

The owner can revoke YouTube access from their Google Account permissions and delete locally stored MCP credentials. Revoking access prevents further authorized API calls until renewed consent.
